WHAT THIS STICK IS
This stick holds {product}, a program that saves YouTube playlists so you can watch
them offline, together with your saved library. Nothing needs to be installed
on the computer you plug it into.

START ON WINDOWS
Double-click "Start YTOP (Windows).cmd". If Windows SmartScreen shows a
warning, click "More info" and then "Run anyway".

START ON MAC
Double-click "Start YTOP (Mac).command". If macOS blocks it, right-click the
file, choose Open, and confirm. You only need to do this once.

START ON LINUX
Open a terminal and run:
  sh "/run/media/$USER/{drive}/start-ytop-linux.sh"
The first time, Linux copies {product} into ~/.cache/ytop (about 300 MB). This is
safe to delete; it will be copied again when needed.

PHONES AND TABLETS
Open the "YTOP Library" folder in the Files app. iPhone and iPad need the VLC
app to play .webm videos. Android plays them in Files or in VLC.

STOPPING
Choose Quit in the app and wait for the "safe to unplug" message before
removing the stick.
